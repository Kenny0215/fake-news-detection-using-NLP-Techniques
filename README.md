# 📰 Fake News Detection Using NLP Techniques

This project focuses on detecting **fake and real news articles** using **Natural Language Processing (NLP)** and **Machine Learning** techniques.  
It aims to help identify misleading information by analyzing textual patterns and linguistic features in news content.

---

## 📌 Project Overview

With the rapid spread of misinformation online, fake news has become a serious issue.  
This project applies NLP preprocessing and machine learning models to classify news articles as **Fake** or **Real**.

---

## 🎯 Objectives

- Preprocess text data using NLP techniques
- Extract meaningful features from news articles
- Train and evaluate machine learning models
- Accurately classify news as **Fake** or **Real**

---

## 🧠 Techniques Used

### 🔹 Natural Language Processing
- Text cleaning
- Tokenization
- Stopword removal
- Lemmatization / Stemming
- TF-IDF Vectorization

### 🔹 Machine Learning Models
- Logistic Regression

---

## 📂 Dataset

The dataset contains labeled news articles:
- **Fake news**
- **Real news**

Example features:
- Title
- Text
- Label

> Dataset source: Kaggle (Fake and Real News Dataset)

> https://www.kaggle.com/code/mohamedasak/fake-news-detection-nlp-logistic-regression
